Private household backup connection

Kauri Backup

Kauri Backup is an operator-managed connection for storing encrypted backups in the operator's own Google Drive account and retrieving them for recovery. It uses restic for client-side encryption and rclone for transfer to Google Drive.

This connection is being set up and validated. It is not a public backup service, and this website does not provide account registration or access to backups.

Google Drive access

The connection requests drive.file access for files it creates or that the account owner explicitly makes available to it. It does not request Gmail access or access to every file in Drive.

Encryption and control

Backup file contents are encrypted locally before upload. The backup encryption password is kept separately from the Drive backup. Google still receives storage and access metadata. Encryption does not prevent deletion of a backup by an account or credential with permission.

Only the operator authorizes the connection and manages backup and recovery actions. There is no public sharing of backup contents through this website.
