Kauri Backup

Privacy policy

Effective 25 September 2026. This policy covers the Kauri Backup Google Drive connection and this information website, not other Kauri channels or services. The connection is being set up and validated for personal use by the owner of mbell-nzl. It is not offered as a service to the public.

Access and purpose

When authorized, the connection uses Google's drive.file permission to create, read, update and manage the files it creates or that the account owner explicitly makes available to it. It handles encrypted repository objects and their file identifiers, sizes and timestamps for backup, integrity checking and recovery. This permission can also allow deletion of those files; it is not an append-only grant.

The connection does not request Gmail access or general access to all Drive files. Data obtained through this connection is used only for backup operations and recovery, not advertising, sale, profiling or training AI models.

Storage and protection

Restic encrypts backup contents on the operator's computer before rclone uploads them to the operator's Google Drive. The backup encryption password is kept separately in the operator's password manager, not in the Drive backup. OAuth credentials are kept in operator-controlled local configuration, outside backup sources and this website.

Google receives encrypted repository objects and operational metadata, including object sizes, access times and connection information. Restored files are decrypted locally into an operator-selected location. Local tools may produce operational logs that the operator must protect. Encryption is not a guarantee against loss, deletion or compromise of the operator's computer or accounts.

Sharing and service providers

Backup contents are not published by this website or intentionally shared with other users. Google provides account authorization and cloud storage under its privacy policy. Restic and rclone run locally; this connection does not send backup contents to an AI provider.

Retention, deletion and revocation

The operator controls how long backups and restored copies are retained. No automatic retention or deletion schedule is currently configured. Revoking the connection in the Google account's third-party connections settings stops authorized access; it does not itself delete existing backups or local copies. The operator must separately manage their deletion, including any provider trash or retention behavior.

This website

These pages contain no sign-in form, upload facility, analytics code or tracking scripts added by Kauri Backup. GitHub Pages hosts the site and may process visitor information, including IP addresses in security logs, under the GitHub privacy statement. Visiting these pages does not authorize Drive access.

Questions and changes

The account owner manages this personal-use connection. Questions can be directed to the support email shown in its Google application configuration. Do not share private files or credentials through public GitHub issues. This page will be updated if these practices change.
